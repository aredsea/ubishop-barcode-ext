# 검수 원장 (REVIEW LEDGER)

이 저장소의 외부·내부 검수 결과를 남긴다. **다음 검수 브리프에 아래 「누적 판정」 절을 그대로 붙여 넣는다.**
안 그러면 이미 근거를 대고 기각한 지적을 매 라운드 다시 받아 비용만 늘어난다.

검수자에게 함께 넘길 한 줄: *"아래는 이미 판정된 지적이다. **같은 것을 다시 내지 마라.**
다만 **근거가 달라졌다고 판단하면 그 근거를 적고** 다시 내도 된다."*

🔴 **검수 중에는 대상 파일을 고치지 마라.** 브리프에 `git hash-object` 값을 박고 검수자가 시작·종료에
대조하게 한다. 1회차에 검수 중 파일이 3번 바뀌어 판정이 어긋난 적이 있다.

### 편향 관찰 (모델별 성적)

- **가장 무거운 건은 전부 내부 Opus 5 가 잡았다** — 진단 신호 소멸(#3), 라벨 폴백의 데이터 파괴(#13),
  사이드바 경고가 사실상 안 뜸(#22), 테스트가 기능 무력화를 놓침(#23~26).
  외부 패널은 그중 어느 것도 못 냈다. **내부 검수 자리를 빼면 안 된다.**
- **Luna 는 세 라운드에서 9건을 내 6건이 채택됐다.** 최저가 자리가 값을 한다.
- **GLM 은 세 라운드 연속 0건**($0.61 소진). 이 저장소에서는 값을 못 하고 있다 —
  다음 회차에도 0 이면 자리를 빼는 것을 검토할 것.
- **K2.7·DeepSeek 도 이 저장소에서는 단독 적발 0.**
- 자체 변이 하네스가 낸 것(#12)도 있다. **변이 검증은 모델 검수와 겹치지 않는 값을 낸다.**
